# methods
Repository for discussion of methodology issues and providing quantitative support

## How it's organized

This repository hosts [discussions](https://github.com/cornerstone-data/methods/discussions) along with supporting files that are designed to use background, argument and evidence that provide support for methodology decisions.

Discussions are organized by general topic and tagged with labels for more specific topics. Discussions is where background should be presented as needed and evidence should be provided.  

[Issues](https://github.com/cornerstone-data/methods/issues) are used to create and assign tasks to contribute to or moderate discussions. 

The main content of the repository is reserved for code and data that provide background or support arguments in the discussions. They should be organized by issues where the background or evidence is requested.
Code and files should be initially added in a branch of main and a [pull request](https://github.com/cornerstone-data/methods/pulls) should be used to have another team member review the work before it is merged. 
Once merged make sure to link to it in the appropriate discussion.
